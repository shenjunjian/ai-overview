# 棋盘、棋谱与走子

改棋子图形、页面布局、中文棋谱或着法校验时读这份约定。FEN 仍是引擎和内部局面的事实来源；界面不编辑 FEN。

## 布局

页面始终左右两栏，最小宽度约 900px。左栏是棋盘和棋谱，右栏是对话。窄屏保持左右，由页面横向滚动，不改成上下堆叠。红方在棋盘下方。

## 棋子

`react-xiangqiboard` 只负责坐标、拖拽和 PV 箭头。棋子用 `customPieces` 画成汉字圆子：

- 红方：帅、仕、相、马、车、炮、兵
- 黑方：将、士、象、马、车、炮、卒

## 棋谱

左栏棋谱代替局面 FEN 编辑框。每一行一个回合：行首是回合数字，第一列红方着法，第二列黑方着法。

```
1  炮二平五  马二进三
2  马二进三  炮二平五
```

记谱用汉字路数。红方从自己右侧数一到九，黑方也从自己右侧数一到九。

- 车、炮、兵、卒、帅、将：进和退记步数，平记到达的路
- 马、相、象、仕、士：进和退记到达的路
- 同一路有两个相同棋子时写前、后；三个写前、中、后；再多则前、二、三、四、后

分析返回的 PV 只画在当前棋盘上，不改写棋谱。

## 走子

红黑轮流。一步走完，行棋方换成对方。只接受当前行棋方的棋子，并且这一步符合该棋子的走法：

- 帅、将：九宫内直走一步
- 仕、士：九宫内斜走一步
- 相、象：走田，相眼要空，停在己方河界这边
- 马：走日，马腿要空
- 车：直线走，途中无子
- 炮：不吃子时途中无子；吃子时中间恰好一个炮架
- 兵、卒：过河前只向前一步；过河后可向前或横走一步

走完后，本方将帅不被将军。将帅同一路且中间无子，也算被将军。不合走法或送将时棋子回到原位，界面说明原因。棋子不能拖出棋盘拿走。

校验和记谱在 `src/lib/xiangqi/play.ts`。
