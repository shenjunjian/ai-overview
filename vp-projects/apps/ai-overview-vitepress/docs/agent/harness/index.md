# harness

一个成熟的智能体产品，就是一套harness系统，比如 PI, dsh, opencode, 泄漏的claude code, codex, ... ， 主流语言是 ts, python, go, rust 等。

通常是开箱即用的产品， 但是 ai-sdk, mastra, codex等也开源自己的harness或agent 供大家二次开发使用。每一个harness 都有许多的设计在里面，可以借鉴学习。
