# 代理循环

代理循环，从狭义上讲就是 `ReAct 模式` ，即 `推理 + 行动`，就是程序如何响应AI的消息体，然后再次循环对话。广义的讲，它包含了如何调用工具，调用子agent, 如何动态更新词，更新每一步的工具，如何顺序执行，或并行派发任务/代理，如何结束任务等，从某种角度上，它就是 `harness core` ,harness的核心部分。

通过`ai-sdk` 库的演化，可以看到它是从 `函数 =》 agentLoop => harness` 三个阶段， `mastra`库也是区分 `代理 =》 harness` ， 所以我们有必要单独了解代理循环
